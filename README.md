# Trade AI — MOEX ISS (Android Studio)

Новая версия прототипа с прямым подключением к публичному MOEX ISS, без подключения к Т-Инвестициям.

## Что реализовано
- Получение минутных свечей фьючерсов с публичного `https://iss.moex.com/iss`.
- По умолчанию указан тикер `CRZ6` как предварительный код CNY-12.26. Если биржа не вернёт данные, проверьте короткий код инструмента в карточке MOEX и введите его в поле приложения.
- Обновление при запуске и далее каждые 5 минут; есть ручная кнопка.
- Отображение последних 90 минутных свечей.
- Расчёт RSI(14), EMA(12), EMA(26), разницы EMA как упрощённого MACD.
- Формирование интервалов 5, 15, 30 и 60 минут из минутных свечей.
- Никаких торговых заявок и подключения к брокерскому счёту.

## Ограничения
- Публичный ISS предоставляет данные с задержкой; ориентир для бесплатного доступа — около 15 минут. Частота опроса приложения не превращает задержанные котировки в реальные.
- В текущем прототипе расчёт RSI упрощённый (среднее изменение за последние 14 периодов), MACD показан как EMA12−EMA26 без сигнальной линии/гистограммы.
- Интервалы 5/15/30/60 минут агрегируются из полученного набора минутных свечей; при неполном наборе данные могут быть неполными.
- Код `CRZ6` задан предварительно. Тикер можно изменить вручную.
- Приложение требует интернет и Android Studio для сборки APK.

## Запуск
Откройте папку `TradeAI_MOEX` в Android Studio, дождитесь синхронизации Gradle и нажмите Run.
Для APK: Build → Build Bundle(s) / APK(s) → Build APK(s).

## Endpoint
`/iss/engines/futures/markets/forts/boards/rfud/securities/{ticker}/candles.json?from=YYYY-MM-DD&interval=1&iss.meta=off`
